# mobile/

This directory will hold the Walris mobile application: React Native + Expo, TypeScript,
Expo Router, NativeWind, React Native Reusables, and TanStack Query.

It is intentionally empty of app code right now. The Expo project itself is scaffolded in
**Milestone 4 — React Native Foundation** (see `docs/03-development-roadmap.md`), which uses
`create-expo-app` to generate the project. Pre-creating a `package.json` here would conflict
with that scaffolding step, so this folder is a placeholder until then.
