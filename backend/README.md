# backend/

This directory will hold the Walris FastAPI backend: Python, Pydantic, SQLAlchemy, and Alembic.

The full application structure (`app/main.py`, `core/`, `routers/`, `services/`, `schemas/`,
`models/`, `utils/`) is scaffolded in **Milestone 3 — Backend Foundation** (see
`docs/03-development-roadmap.md`).

A Python virtual environment lives at `backend/.venv` (gitignored). Activate it with:

```bash
source backend/.venv/bin/activate
```
